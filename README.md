# Super-Market-Analysis
# Setup
1. Install MongoDB Community Server (and optionally MongoDB Compass) and make sure the service is running on `localhost:27017`.
2. `pip install pymongo pandas numpy scikit-learn matplotlib seaborn`
3. Keep `SuperMarket Analysis.csv` in `C:\Users\adars\OneDrive\Desktop\Supermarket` (or beside `main.py`).
4. `python main.py` — charts and `results.json` appear in an `output` folder next to the script.
Set `SHOW_PLOTS = True` in `main.py` to see charts on screen. Set `MONGO_URI` as an environment variable for Atlas.
